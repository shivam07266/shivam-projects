# Rock Paper Scissors Game 🎮

A simple command-line Rock Paper Scissors game built using Python.  
The player competes against the computer, with score tracking and input validation for a smooth gameplay experience.

## 📌 Features

- Play Rock, Paper, Scissors against the computer
- Random computer choices using Python's `random` module
- Real-time score tracking
- View current score anytime during the game
- Final score display when exiting
- Handles invalid inputs without crashing
- Clean game structure using functions

## 🛠️ Concepts Used

- Python functions
- Loops (`while`)
- Conditional statements (`if/elif/else`)
- Dictionaries for game logic
- Exception handling (`try/except`)
- Random number generation
- User input handling

## 🎮 How to Play

1. Run the Python file
2. Choose an option:

```
0 - Exit game
1 - Rock
2 - Paper
3 - Scissors
4 - View score
```

3. The computer randomly selects its choice
4. The winner is decided and the score is updated

## ▶️ How to Run

Make sure Python is installed on your system.

Clone the repository:

```bash
git clone <repository-link>
```

Navigate to the project folder:

```bash
cd rock-paper-scissors
```

Run the game:

```bash
python rock_paper_scissors.py
```
