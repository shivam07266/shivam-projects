# 🎯 Number Guessing Game

A simple Python-based number guessing game where the player tries to guess the number chosen by the computer. The game includes different difficulty levels, attempt limits, and hints to help the player guess correctly.

## 📌 Features

- Random number generation
- Three difficulty levels
- Limited attempts based on difficulty
- Higher/lower hints
- Input validation
- Simple command-line interface

## 🎮 How It Works

1. Choose a number range:
   - Easy: 1 - 50
   - Medium: 1 - 100
   - Hard: 1 - 150

2. Choose difficulty:
   - Easy: 10 attempts
   - Medium: 7 attempts
   - Hard: 5 attempts

3. Try to guess the computer's number before running out of attempts.

The game gives hints:
- "Go higher" if your guess is too low
- "Go lower" if your guess is too high
- "Very close" when you are near the answer

- Python 3
- Random module
