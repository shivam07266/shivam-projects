# 🔐 Password Generator

A simple Python-based password generator that creates customizable strong passwords based on user preferences.

## 📌 About Project

This project allows users to generate random passwords by selecting:
- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols

It also checks the generated password strength and gives a basic strength rating.

## ✨ Features

- Generate random passwords
- Choose password length
- Include/exclude uppercase letters
- Include/exclude lowercase letters
- Include/exclude digits
- Include/exclude symbols
- Password strength checker

## 🛠️ Technologies Used

- Python 3
- Built-in Python libraries:
  - `random`
